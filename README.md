# Iceland Fishing App — Support

This is the **public project information and support channel** for **Iceland Fishing**, an Android fishing research and conditions app being developed for Iceland.

**Current status:** private development preview. The app is **not published** or offered for download here. This repository does not contain the private Android app, datasets, maps, credentials or unpublished fishing locations.

## Help and feedback

[**Open a support request or report a bug**](https://github.com/68erko68-art/iceland-fishing-app-support/issues/new/choose)

[View existing issues](https://github.com/68erko68-art/iceland-fishing-app-support/issues)

You can use GitHub Issues to report an app crash, stale weather forecast, incorrect attribution, accessibility problem, data-quality concern or feature request. An active GitHub account is needed to open an issue. Please do **not** include private addresses, location history, account credentials or personal data in a public issue.

For a weather-data/provider concern, please include the relevant **data provider, source timestamp and affected app version** if known—without posting private information.

## What the app aims to offer

The app is intended to bring Icelandic coastal and freshwater fishing research together with **source-labelled weather forecasts, tides, marine conditions, fish-species information and official access/permit references**, using commercially reusable data where rights are verified.

A forecast is not a direct instrument observation. Historical scientific surveys do **not** prove an individual fishing spot is legally accessible or predict the chance of catching a fish. The app will identify data source, time and uncertainty.
